# 🏧 ATM Interface

## DecodeLabs Java Internship – Project 3

A console-based ATM simulation built with Java. This project demonstrates object-oriented programming principles including encapsulation, separation of concerns, and robust input validation.

---

## 🚀 Features

- **Deposit money** – add funds to your account
- **Withdraw money** – remove funds (with overdraft protection)
- **Check balance** – view current account balance
- **Exit** – safely end the session

### Input Validation

- Prevents crashes on invalid inputs (letters, symbols, out-of-range numbers)
- Clear error messages guide the user
- Sufficient balance check before withdrawal

---

## 🛠️ How to Run

1. **Compile all Java files:**
   ```bash
   javac BankAccount.java ATM.java Main.java
   
2. **Run**
   ```bash
   java Main
